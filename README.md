# 🌍 ExploreWorld – Travel Website

ExploreWorld is a modern and responsive travel website designed to help users discover beautiful destinations around the world. It features attractive destination cards, travel packages, search filters, ratings, pricing, and interactive booking buttons.

## 🚀 Features

- Responsive and modern homepage.
- Attractive travel hero section.
- Destination cards with images.
- Destination search functionality.
- Category-based destination filtering.
- Travel package pricing and duration.
- Destination ratings.
- Interactive Book Now buttons.
- Mobile-friendly navigation menu.
- About and Contact sections.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts and responsive design.
- **JavaScript** – Search, filtering and interactivity.
